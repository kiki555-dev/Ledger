# Ledger — калькулятор ROI и NPV

Финансовый калькулятор: по начальным инвестициям и месячному денежному потоку считает
NPV, ROI и срок окупаемости и рисует график накопленного денежного потока.

**Открыть:** https://kiki555-dev.github.io/Ledger/

## Что умеет
- NPV с дисконтированием по месячной ставке
- ROI за выбранный горизонт
- Срок окупаемости — первый месяц, когда накопленный поток выходит в плюс
- График на Canvas: убыточный участок рыжий, прибыльный — зелёный
- Валидация ввода с понятными сообщениями
- Адаптивная вёрстка

## Стек
HTML, CSS, JavaScript (без фреймворков и библиотек), Canvas API
